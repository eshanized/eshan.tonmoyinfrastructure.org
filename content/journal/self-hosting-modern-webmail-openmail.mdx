## 1. Digital Sovereignty & The Centralization of Email

Email is one of the few foundational decentralized protocols remaining on the internet. However, over 85% of global corporate and personal email is now routed through just two hyperscalers: Google Workspace and Microsoft 365.

This centralization creates critical structural risks:
1. **Arbitrary Account Freezes**: Automated AI risk models routinely lock accounts without human recourse or explanation.
2. **Bulk Telemetry Harvesting**: Cloud providers parse message metadata and receipt bodies for advertising and training data.
3. **Operational Fragility**: Outages in single cloud availability zones disrupt communication across thousands of independent businesses simultaneously.

While open-source mail transfer agents (such as Postfix, Dovecot, and Haraka) provide rock-solid backend infrastructure, the webmail user interface layer has been stuck in the 2000s. Legacy interfaces like Roundcube and SquirrelMail feel sluggish, clunky on mobile devices, and require complex CLI file editing to configure.

We created **OpenMail** (`github.com/eshanized/OpenMail`) to solve this.

## 2. Zero-CLI Setup Wizard

A primary barrier to self-hosting email is setup friction. Configuring database connections, IMAP ports, SSL certificates, and admin credentials in plaintext `.conf` files causes many teams to give up and return to proprietary cloud suites.

OpenMail introduces a **browser-first graphical installation wizard**:

```
[Step 1: Environment Health Check]
  - PHP 8.2+ runtime verification
  - Sodium, OpenSSL, and IMAP extension checks
  - Directory write permissions (/storage, /bootstrap/cache)

[Step 2: Database Connection Test]
  - Live probe of MySQL / PostgreSQL / SQLite socket
  - Automated schema migration with progress telemetry

[Step 3: Mail Server Handshake]
  - Real-time STARTTLS handshake test with Postfix/Dovecot
  - Authentication verification before finalizing settings

[Step 4: Administrator Onboarding]
  - Salted Argon2id credential hashing
  - Immediate redirect to modern inbox cockpit
```

This reduces the time required to deploy a modern, functioning webmail interface from hours to **less than 3 minutes**.

## 3. Architecture & Protocol Compliance

OpenMail adheres strictly to standard email RFCs:
- **IMAP4rev1 (RFC 3501)** for folder synchronizations, message flags (`\Seen`, `\Flagged`, `\Draft`), and MIME body part parsing.
- **SMTP (RFC 5321)** with mandatory STARTTLS transport security.
- **Clean Responsive UI**: Engineered with Tailwind CSS and reactive components, delivering 60 FPS transitions and full mobile touch optimization.
